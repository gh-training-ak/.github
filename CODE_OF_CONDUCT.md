# Code of conduct

Organisation default.

## Our standard

Be direct about code and kind about people. Review the change, not the author.

Expected:

- Explain why, not only what. "This is wrong" is not a review comment.
- Assume the author had a reason. Ask before you rewrite.
- Disagree in the open, decide, then move together.

Not acceptable:

- Personal remarks, demeaning comments, or sustained disruption of discussion.
- Publishing anyone's private information.
- Claiming someone else's work.

## Scope

Issues, pull requests, discussions, wikis, and anywhere somebody is representing a
project in this organisation.

## Enforcement

Report to the organisation owners. Reports stay confidential. Consequences range from a
private correction to removal from the organisation.
