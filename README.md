# .github

Organisation defaults for `gh-training-ak`.

| Path | What it does |
| --- | --- |
| `profile/README.md` | Renders on the organisation profile page |
| `CONTRIBUTING.md` | Default contributing guide for every repository without its own |
| `CODE_OF_CONDUCT.md` | Default code of conduct |
| `SECURITY.md` | Default security policy and reporting route |
| `SUPPORT.md` | Default support routing |
| `FUNDING.yml` | Default sponsor button configuration |
| `.github/ISSUE_TEMPLATE/` | Default issue forms |
| `workflow-templates/` | Starter workflows offered in the Actions tab of every repository |

A repository that has its own copy of any of these wins. Nothing here overrides a
repository, it only fills a gap.

Note the asymmetry that catches people out: community health files live at the **root**
of this repository, while issue templates and workflow templates live under `.github/`
and `workflow-templates/` respectively.
