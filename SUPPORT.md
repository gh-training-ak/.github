# Support

Organisation default.

| You want to | Go to |
| --- | --- |
| Ask how something works | The repository's Discussions tab |
| Report a defect | A new issue, using one of the forms |
| Report a vulnerability | Private vulnerability reporting |
| Understand why something is built this way | `docs/adr/` in the repository |

These are teaching repositories. There is no support contract behind them and no on call
rota, whatever the wiki says.
